# 版本演进

[← 返回首页](../README.md) · [English](changelog.en.md)

按开发阶段梳理的里程碑，不是逐条更新日志。当前版本 **2.1.5**。

---

## 起点：基于 Feather 与 Ksign

易能签的代码基础来自开源签名工具 [Feather](https://github.com/claration/Feather)，并以 [Ksign](https://github.com/Nyasami/Ksign) 为直接上游。从上游继承下来的能力包括：Zsign 签名内核、软件源（AltStore 源格式）标签页、文件浏览器、软件库批量导入与删除、证书吊销检测、「仅修改不签名」选项、主题色自定义、备用图标选择。

---

## 2.0.x 早期（2026 上半年）

这一阶段的重点是把上游的通用工具，改造成面向中文用户的完整签名 App。

**签名与注入**
- 插件注入体系成型：dylib / deb / framework 三类插件、插件分组管理
- 越狱依赖处理从「无条件注入」改为按依赖判定，随后收敛到 **ElleKit 单线**，Substrate 分支整体下线
- 新增「修复白图标」「修复深色图标（iOS 18）」选项
- 签名日志重做为结构化清爽格式，隔离 zsign 的原始输出，改为逐行流式渲染

**编辑与查看**
- 文本编辑器接入 Runestone，带行号与多语言语法高亮，补齐查找 / 跳转 / 编码切换 / 自由字号
- Plist 编辑器与 Hex 编辑器重构：分页、撤销重做、类型感知
- 新增 Assets Catalog（`.car`）预览

**文件与下载**
- 文件浏览器整体重做，加入目标选择器、新建文件夹、面包屑、冲突预警
- 下载器从独立标签页并入文件页，改为任务列表，链接自动填剪贴板，按日期与类型自动归档
- 文件传输页（电脑浏览器无线传输）重新设计

**证书**
- 证书页面重构：列表布局、自动状态检测、到期与权限展示
- 新增 URL Scheme 导入证书（`enq-app://`）与「复制 AI 对接文档」
- 加入云端证书恢复；导入拒收 IPA 与大压缩包，多证书压缩包可选择

**系统集成与本地化**
- 分享导入从 Share Extension 方案改为 **Document Types「打开方式」**
- 灵动岛 / 锁屏实时活动接入签名进度，并做节流处理
- 语言体系整理为简体中文 / 繁體中文 / English / Tiếng Việt（越南语），切换后立即生效
- 生物识别锁、隐私协议闸门、崩溃采集（同意后才初始化）

## 2.0.7 – 2.0.9（2026 年 7 月）

- **一键自动更新上线** —— 自动匹配安装证书、提交重签任务、服务端完成签名并准备安装，配套分步进度页与独立错误页；该能力对所有用户免费
- 软件源导入新增进度与结果展示，导入过程有反馈；重写解锁流程，优化刷新指示与请求队列管理
- 软件源体验大幅优化：落盘缓存让冷启动不再全量重拉，首屏并发解缓存 + 逐条上屏，网页链接改用内置浏览器打开
- 存储空间页支持查看与清理软件源缓存
- 外观设置支持切换 App 图标（曜蓝 / 紫晶 / 碧璃 / 琥珀）
- 签名页新增「输出」区块：可改输出文件名、可选 IPA / TIPA
- 文件名规则默认加上时间戳
- 修复签名设置在 App 更新后被重置的问题
- 后端服务上线：在线重签通道、软件源与版本管理、设备统计、UDID 获取页面

## 2.1.x（2026 年 7 月底至今）

### 2.1.5（2026 年 8 月）

- 新增「钥匙串隔离」，提升签名应用的数据安全性
- 优化灵动岛与锁屏实时活动，任务完成后可快速安装或继续签名
- 修复实时活动完成按钮无法正常打开对应页面的问题
- 提升文件后台下载的稳定性
- 将「搜索」入口调整为「软件源」，优化入口、页面布局和添加流程
- 调整部分图标、按钮文案及翻译

**产品化**
- 显示名正式定为 **EnSIgn**，补齐 InfoPlist 本地化
- 关于页重做：致谢、官网入口、由 LicensePlist 自动生成的开源许可清单
- 设置 / 文件 / 软件源三处页面统一字号与分组样式
- 新增应用内**匿名工单**系统，支持附件与私聊回复

**功能**
- **App 多开**：一次签名签出多个独立副本，支持批量签出
- 已签名应用支持**扫码安装**
- 文件管理器支持 `tar` / `gz` / `xz` / `bz2` / `lzma` / `7z` 解压，IPA / TIPA 也能直接解
- 软件源支持下载非 IPA 文件并标记已下载；插件页支持从应用内文件管理器选择
- 快捷设定新增「修复越狱依赖」开关，说明清楚改的是 `LC_LOAD_DYLIB`
- iOS 16 / 17 改用自定义标签栏，旧系统上搜索页回到软件库右侧

**性能与稳定性**
- 打包链路改用 APFS 克隆，去掉进度轰炸；IPA 导入去掉三处无谓开销
- 后台保活改成「按需登记 + 停滞自动放手」，不再长期挂着
- 软件源列表去掉逐行开销并开启 ProMotion 高刷
- 适配 iOS 26 起外部分享文件的权限变化
- 灵动岛与锁屏卡片样式重做，修复品牌角标与展开态问题
