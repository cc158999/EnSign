## 〇、一键自动更新（重点功能）

自签装上的应用没有 App Store 更新通道。易能签把「找新包 → 导入 → 选证书 → 重签 → 再装」这一整串收成了一次点击：

```
自动匹配安装时用的证书 → 提交重签任务 → 服务端签名 → 准备安装
```

- **完全免费**，不分证书来源 —— 自有证书与易能签提供的开发者证书一视同仁
- **证书自动匹配**，不用回想当初用了哪一张
- 有独立的**分步进度页**；失败进独立错误页并给出可读原因
- 交出安装链接后自动切到后台，让系统安装接管
- 重复提交复用已有任务，不会在服务端重复起签名进程；队列繁忙时明确提示稍后重试
- 与本地签名是两条独立的路 —— 日常给第三方 IPA 签名仍是纯本地流程

细节与隐私边界见 **[自动更新说明](auto-update.md)**。

## 一、签名

### 签名内核

- 基于 **Zsign** 的原生重签名，全过程在设备本地完成，不上传证书与安装包
- 支持三种模式：
  - **证书签名** —— p12 + 描述文件正常重签
  - **Ad-hoc 签名** —— 无证书情况下的临时签名
  - **仅修改配置不签名** —— 只改包内信息、不动签名，适合已经签好的包做微调
- 签名完成后可直接输出 **IPA** 或 **TIPA**（TrollStore 包）

### 输出控制

- 自定义输出文件名，支持文件名规则模板，默认自动附加时间戳避免覆盖
- 可选压缩级别（从「不压缩、最快」到「最小体积」），在打包速度和产物大小之间取舍
- 打包链路使用 APFS 克隆，避免大包重复拷贝带来的等待

### 批量与队列

- 软件库支持多选批量签名，一次排队签完
- 处理队列页可查看每个任务的实时状态
- 相同任务重复提交会复用已有任务，不会重复起进程

### App 多开

- 一次签名可签出多个副本，每个副本自动获得独立的 Bundle ID
- 可与原版应用共存于桌面

### 数据安全

- 可开启「钥匙串隔离」，为签名应用使用独立的钥匙串访问组，减少不同侧载应用之间的数据互访

### 签名日志

- 结构化、分阶段的签名日志（读取包 → 改配置 → 注入 → 签名 → 打包）
- 日志逐行流式渲染，签名过程中就能看到进展
- 完整日志可导出或复制，排查问题时直接发给开发者
- 显示精确耗时（精确到毫秒级，如 `1.46s`）

## 二、修改应用

- **基础信息**：应用显示名、Bundle Identifier、版本号、Build 号，均可在签名页直接编辑
- **应用图标**：从相册或文件替换图标
- **Info.plist 键值编辑**：不满足于预设项时，可直接对包内 Info.plist 做键值级增删改
- **修复白图标**（Fix White Icon）：处理某些包安装后图标显示异常的问题
- **修复深色图标**（Fix Dark Icon）：移除 `UIPrerenderedIcon`，适配 iOS 18 的深色/单色图标
- **移除描述文件**：可选择是否把 embedded.mobileprovision 写进产物
- **自动清理**：移除旧的 `_CodeSignature`、失效的 Watch 占位应用、同步更新 Extension 的 Bundle ID
- **依赖展示**：签名前可查看主二进制的架构与依赖 dylib 列表

---

## 三、插件注入（Tweak）

- 支持注入 **dylib / deb / framework** 三类插件
- **插件仓库**：内置 Tweaks 目录管理，可从软件源下载插件、从文件管理器选取、或外部分享导入
- **插件管理页**：真实文件夹浏览，支持搜索、显示文件大小、异常警告、彻底删除裸 dylib
- **越狱依赖修复**：
  - 依赖统一收敛到 **ElleKit** 单线，改写插件的 `LC_LOAD_DYLIB` 指向
  - 只有真正存在越狱依赖的插件才会被改写，不做无条件注入
  - 解析不到的依赖降级为**弱链接**并写入日志，避免直接崩溃
  - 优先就地使用 App 自带的运行时，不重复塞入
- **移除注入**：可列出并移除已注入的 dylib，包括 `.app` 根目录下的（不限于 Frameworks）
- 注入的每个阶段都会写入签名日志，方便定位失败点

## 四、证书管理

- **多种导入方式**：
  - p12 + mobileprovision 文件对
  - `.ESignCert` 加密证书包（自带密码，点开即导入）
  - 从压缩包批量导入，包内含多张证书时可选择
  - **URL Scheme 导入**（`enq-app://`）—— 供证书商网页一键推送证书；App 内还提供「复制 AI 对接文档」，把对接规范一键交给 AI 帮你写接入代码
- **去重保护**：证书与描述文件都相同才算重复，拒绝重复导入
- **状态检测**：
  - 吊销状态检测（可手动刷新）
  - 到期时间与剩余天数以胶囊标签直观展示
  - 证书 CN、团队、权限（Entitlements）列表可查看
- **云端恢复**：支持从云端恢复此前使用的证书，换机或重装后不用重新找文件
- **安全存储**：证书密码经加密后落库，不保存明文

---

## 五、软件库

- **已签名 / 未签名**分栏管理，各自独立列表
- 每行显示应用图标、名称、Bundle ID、版本、大小、签名时间等多行信息
- **批量导入**：一次导入多个 IPA
- **批量删除**：多选删除，删除有统一确认，不会误触
- **安装方式**：
  - 本地 **HTTPS 安装服务**（内置自签 TLS + `itms-services://`），点一下直接装
  - **扫码安装** —— 生成二维码，装到另一台设备上
  - 安装过程有独立进度与错误页，失败原因可读
- **长按菜单**：在文件管理器中打开、分享、查看详情
- 安装完成后自动清理临时 IPA 缓存

---

## 六、软件源（App Store 标签页）

- 兼容 **AltStore / ESign** 源格式，包含加密源与混淆源的解析
- 支持 **全能签软件源（未加密格式）**，老用户的源列表可以直接搬过来
- **源管理**：一键添加源，添加成功后直达源列表
- **公告板块**：展示源作者发布的 News
- **筛选与搜索**：列表内筛选，另有独立的搜索标签页
- **应用详情**：iTunes 截图与评分展示、详情页配色自适应应用图标主色、骨架屏加载
- **下载**：
  - 防重复下载
  - 支持下载非 IPA 文件（dylib / deb / framework 自动落进 Tweaks 目录），并标记已下载
  - 下载进度接入灵动岛
  - 源里的网页链接用内置浏览器打开，不会被当成安装包硬下
- **性能**：源数据落盘缓存，冷启动不用全量重拉；列表使用 UIKit 桥接渲染，万级应用列表也能顺滑滚动，并开启 ProMotion 高刷
- **自建源**：同作者的 [EnqAppstore](https://github.com/cc158999/EnqAppstore) 提供配套的源托管服务端，部署后产出的源可直接被易能签添加

---

## 七、文件管理器

- 完整的沙盒文件浏览器：新建文件夹、重命名、移动、复制、删除、面包屑导航、搜索、目标选择器与冲突预警
- **解压**：
  - 支持 `zip` / `tar` / `gz` / `xz` / `bz2` / `lzma` / `7z`，以及 `ipa` / `tipa` / `deb`
  - 点击 `.zip` 直接解压，不再走预览
  - 解压带进度浮层，不覆盖同名文件夹
- **文件传输**：开启后在电脑浏览器输入地址即可上传下载文件，无需数据线
- **内置下载器**：
  - 链接自动读取剪贴板
  - 自动嗅探 IPA / TIPA / ZIP / Dylib / Deb 类型，按「日期 + 类型」自动归档
  - 下载任务列表，完成后自动跳转到对应位置
- 图片文件直接以缩略图预览；其他类型走 QuickLook

## 八、编辑器与查看器

| 工具 | 能力 |
|---|---|
| **代码 / 文本编辑器** | 基于 Runestone，带行号与语法高亮（CSS / HTML / JSON / JavaScript / Markdown / Python / YAML）；查找、跳转行号、编码切换、自由字号、底部快捷工具栏 |
| **Plist 编辑器** | 类型感知的键值编辑，树状展开/折叠（点整行即可），全树扁平搜索与计数，撤销重做 |
| **Hex 编辑器** | 大文件分页加载，撤销重做，只读/编辑切换 |
| **Assets.car 预览** | 解析 Asset Catalog，直接查看包内图片资源与规格 |

## 九、设置

- **外观**：主题色自定义、深色/浅色跟随系统、App 图标切换（曜蓝 / 紫晶 / 碧璃 / 琥珀四款内置图标）、iOS 26 Liquid Glass 外观开关
- **签名配置**：默认签名选项、压缩级别、输出文件名规则等集中管理，跨更新不会被重置
- **存档**：签名产物归档管理
- **存储空间**：分类统计各类缓存占用，逐项清理（含软件源缓存、图片缓存、临时文件）
- **语言**：简体中文 / 繁體中文（中国台湾）/ English / Tiếng Việt（越南语）四语完整本地化，切换后立即生效
- **安全**：Face ID / Touch ID 应用锁
- **日志**：运行日志查看与导出，跟随系统明暗
- **反馈工单**：应用内匿名提交工单，支持图文附件与私聊回复，可附带运行日志
- **关于**：版本信息、开发者署名、官网入口、开源许可清单（由 LicensePlist 自动生成）
- **重置**：一键重置为初始状态，原地重建启动流程，不需要退出 App

---

## 十、系统集成

- **灵动岛 / 锁屏实时活动**：实时显示签名与下载进度，任务完成后可快速安装或继续签名
- **「打开方式」导入**：在任意 App 的分享面板里选择易能签，即可导入 IPA / TIPA / ZIP / DEB / dylib / framework / p12 / 描述文件 / `.ESignCert`
- **URL Scheme**：`enq-app://`，支持添加软件源、下载资源与一键导入证书；格式与示例见 [URL Scheme 使用指南](url-scheme.md)
- **后台保活**：按任务智能启停，任务停滞自动放手，不会长期占用后台
- **系统兼容**：iOS 16 起覆盖至最新系统，新系统 API 均有降级路径
- **崩溃防护**：内置自我保护模块，检测到异常环境只做提示，不会自杀式退出
